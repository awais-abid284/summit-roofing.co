# Summit Roofing Co. — Portfolio Website Demo

A responsive multi-page HTML/CSS/vanilla JavaScript website designed as a fictional American roofing contractor portfolio demonstration.

## Run locally
Open `index.html` in a browser, or serve this folder with a local static server (recommended for consistent relative paths):
`python -m http.server 8000`
Then visit `http://localhost:8000`.

## Pages
- Home (`index.html`)
- About (`about.html`)
- Services overview (`services.html`)
- Six service detail pages in `services/`
- Service Areas (`service-areas.html`)
- Projects (`projects.html`) with category filters and lightbox
- Reviews (`reviews.html`)
- Contact / Estimate (`contact.html`)
- Privacy and Terms demo pages

## Important demo disclosures
- Summit Roofing Co. is fictional.
- Phone, email, hours and service area are placeholders.
- No licenses, certifications, awards, customer counts, company history or real reviews are claimed.
- Project gallery images are representative photography, not verified Summit projects.
- The estimate form validates and displays a local demo confirmation only. It does not transmit data. Connect a real form backend before production.
- Replace all placeholder details and add business-approved legal copy before launch.
